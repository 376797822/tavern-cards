# 家庭级角色模板

用于编写以"家庭/家族"为单位的整体条目。此类条目描述一户人家或一个家族的集体设定，涵盖概述、现状、经济、住址布局、成员及成员关系等，供 AI 理解这个家庭作为一个整体如何运作、成员之间如何互动。

## 约束

- 家庭级条目以**家庭/家族整体**为对象，不是单个角色
- 条目使用 `<World_Family_$Name>` XML 标签，`$Name` 替换为家庭名（如"沈家""林氏"）
- 此模板整合了家庭概述、成员档案、关系网络，不再拆分
- 家庭级成员不重复写详细人设——如需主角级/NPC 级的深度设定，单独用对应模版编写，此处只写家庭层面的信息
- 不可被 {{user}} 代入

## 模板结构

```
<World_Family_$Name>
家庭档案:
  概述: ${家庭整体定位——是什么样的人家、在城中/世间的地位、家族特色等}

  现状: ${分条介绍家庭当前处境、主要困境和机会}

  初始长期目标: ${1-3条，方向各不相同，根据家庭信息设定合理的长期目标}
  初始短期目标: ${1-3条，方向各不相同，根据家庭现状设定合理的短期目标}

  经济情况: ${经济来源、收入水平、负债/积蓄、主要开销等}

  住址和住宅布局:
    住址: ${家庭居住地点，明确到可识别的程度}
    布局: ${住宅格局——院落/楼层/房间分布，哪些区域是公开、哪些是私密}

  成员:
    户主/家长: ${姓名、身份、一句话定位}
    其他成员: ${按人列出，每人姓名、身份、年龄、与户主关系}
    仆从/依附人员: ${如有，列出关键人物及职责}

  成员住址:
    同住成员: ${在宅内居住的成员及各自房间/区域}
    外住成员: ${不在宅内居住的成员及各自住址}

  成员间关系:
    主要关系线: ${家庭内部的关键关系——谁亲谁疏、谁主谁从、有无积怨或秘密}
    对外关系: ${家庭与外界的重要关系——联姻、世交、宿敌、依附等}

  其他信息: ${家规、禁忌、家族秘密、历史包袱等其他需注意的信息}

</World_Family_$Name>
```

## 字段说明

### 概述

家庭整体定位。什么人家、什么地位、家族特色。让 AI 知道这个家庭"是什么"。

### 现状

家庭当前处境。分条说明，覆盖主要困境和机会。

### 目标

- **长期目标**：家庭最终想达成的状态（如复兴门楣、摆脱困境、维持地位），写 1-3 条，每条方向各不相同
- **短期目标**：家庭当前最紧迫要做的事，写 1-3 条，每条方向各不相同

### 经济情况

经济来源（产业、俸禄、经商等）、收入水平、负债/积蓄、主要开销。决定家庭能调动多少资源。

### 住址和住宅布局

- **住址**：家庭居住地点，明确到可识别的程度（城/街区/标志物）
- **布局**：住宅格局——院落/楼层/房间分布，区分公开区域（会客）与私密区域（起居），这决定角色在宅内能遇见谁、避开谁

### 成员

- **户主/家长**：姓名、身份、一句话定位
- **其他成员**：按人列出——姓名、身份、年龄、与户主关系
- **仆从/依附人员**：如有，列出关键人物及职责

### 成员住址

- **同住成员**：在宅内居住的成员及各自房间/区域
- **外住成员**：不在宅内居住的成员及各自住址

### 成员间关系

- **主要关系线**：家庭内部关键关系——谁亲谁疏、谁主谁从、有无积怨或秘密
- **对外关系**：家庭与外界的重要关系——联姻、世交、宿敌、依附等

### 其他信息

家规、禁忌、家族秘密、历史包袱等其他需注意的信息。

## 编写顺序

- 家庭级模板在创作规划中列为 `entries` 中的一条，类型按家庭在剧情中的定位归入 `角色` 或 `NPC`，part 为 `family`
- 编写时直接产出完整条目
- 编写完成后在 entryManifest 中注册为 `角色/{家庭名}_家庭` 或 `NPC/{家庭名}_家庭`，使用 `<World_Family_$Name>` 标签
