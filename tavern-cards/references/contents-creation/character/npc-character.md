# NPC 级角色模板

用于编写与主角有深度互动的 NPC 角色。每个 NPC 一条独立条目，信息完整度与主角级接近，但**不可被 {{user}} 代入**。

## 约束

- NPC 级角色不可被 {{user}} 代入
- 条目使用 `<World_NPC_$Name>` XML 标签，`$Name` 替换为角色名
- 此模板整合了基础信息、性格、NSFW 信息，不再拆分条目
- 身份字段按场合拆分，遵循世界书中的身份感知系统
- 必须包含"与主角的相遇可能和展开方向"字段

## 模板结构

```
<World_NPC_$Name>
角色档案:
  初始信息:
    姓名: ${姓名}
    年龄: ${年龄}
    性别: ${性别}
    身份: ${按场合拆分的不同身份}
    样貌: ${简要样貌介绍}
    体格: ${简要体格介绍}
    社交情况: ${社交圈子，日常接触人群，与谁相识、与谁交好或交恶等}

  出身: ${分条介绍来历、历史事件等}

  现状: ${分条介绍当前处境}

  与主角的相遇可能和展开方向: ${可能在什么场景下遇到主角，相遇后可能的发展方向，如可发展关系、可提供帮助、可形成冲突等}

  本领: ${角色拥有的技能和水平}

  性格信息:
    待人接物倾向: ${与他人互动时的思维方式、行为准则、认知状态}
    突发处理倾向: ${处理突发问题时的思维方式、行为准则、认知状态}
    对待善恶倾向: ${面对善事和恶事时的思维方式、行为准则、认知状态}
    对待强弱倾向: ${面对强于自己和弱于自己的人事物时的思维方式、行为准则、认知状态}
    自我推进倾向: ${无目标或完成前一目标后的思维方式、行为准则、认知状态}

  NSFW信息:
    器官信息:
      规格: ${口唇形态、胸部大小及形态、臀型、外阴形态及毛发特征、内阴特征、子宫形态及位置等}
      性能: ${敏感度、湿润程度、高潮特点、反应方式等}
      性知识了解程度: ${对性知识的了解程度，来源为何，是否有实践经验等}
    档案信息:
      历史: ${过往性经历等信息}
      倾向: ${倾向}
      习惯: ${习惯}
      认知: ${认知}
      爱好: ${爱好}

  注释信息: ${其他需注意的信息}

</World_NPC_$Name>
```

## 字段说明

### 初始信息

| 字段 | 说明 |
|------|------|
| 姓名 | 角色姓名 |
| 年龄 | 年龄 |
| 性别 | 性别 |
| 身份 | **按场合拆分**——同一角色在不同场景下身份不同 |
| 样貌 | 简要样貌介绍，遵循"外貌只写特征"原则 |
| 体格 | 体态特征、力量感、健康状况 |
| 社交情况 | 社交范围、日常接触人群、与谁相识、与谁交好或交恶 |

### 出身

角色来历和关键事件。只写对角色产生了实际影响的事。

### 现状

当前处境。分条说明。

### 与主角的相遇可能和展开方向

**核心字段**。描述：
- 可能在什么场景下遇到主角
- 相遇后可能的发展方向：可发展关系、可提供帮助、可形成冲突、可推进剧情等
- 此角色与主角的互动可能产生什么后果

### 本领

角色拥有的技能和水平。

### 性格信息

五项倾向，同主角模板。每个倾向写具体的行为模式和认知状态，不写抽象标签。

### NSFW 信息

| 字段 | 说明 |
|------|------|
| 规格 | 女性器官描述：口唇形态、胸部大小及形态、臀型、外阴形态及毛发特征、内阴特征、子宫形态及位置等 |
| 性能 | 敏感度、湿润程度、高潮特点、反应方式等 |
| 性知识了解程度 | 对性知识的了解程度、来源（书本/实践/听闻）、是否有实践经验 |
| 历史 | 过往性经历 |
| 倾向 | 性倾向、偏好 |
| 习惯 | 性方面的习惯行为 |
| 认知 | 对性和两性关系的认知与态度 |
| 爱好 | 在性方面的具体爱好 |

### 注释信息

其他需要注意的信息。

## 编写顺序

- NPC 模板在创作规划中列为 `entries` 中的一条，类型为 `NPC`，part 为 `major`
- 编写时直接产出完整条目，不再拆分
- 编写完成后在 entryManifest 中注册为 `NPC/{角色名}_NPC`，使用 `<World_NPC_$Name>` 标签

## 自查清单

- [ ] 身份按场合拆分，至少两个不同场景
- [ ] "与主角的相遇可能和展开方向"已填写，包含至少一种相遇场景和一种发展方向
- [ ] 社交情况已填写
- [ ] 五项性格倾向完整，每项有具体行为模式而非抽象标签
- [ ] NSFW 器官信息覆盖口胸臀内外阴子宫，包含性知识了解程度
- [ ] 通用自查：按 `references/rules.md` 通用自查
