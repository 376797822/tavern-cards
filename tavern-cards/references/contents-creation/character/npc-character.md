# NPC 级角色模板

用于编写与主角有深度互动的 NPC 角色。每个 NPC 一条独立条目，信息完整度与主角级接近，但**不可被 {{user}} 代入**。

## 约束

- NPC 级角色不可被 {{user}} 代入
- 条目使用 `<World_NPC_$Name>` XML 标签，`$Name` 替换为角色名
- 此模板整合了基础信息、性格、NSFW 信息，不再拆分条目
- 身份字段按场合拆分，遵循世界书中的身份感知系统
- 必须包含"与主角的相遇可能和展开方向"字段

## 多角色同条目

**一个条目里可写多个同类型角色**（如一群下人仆妇、封建大家庭中的某个小家庭、一个同好会里的成员）。这些角色单独写各自条目会显得零散，合并成一个条目更紧凑。

写法：
1. **先整体简述**：用一两句话概括这组角色的共同点——他们的身份、所处环境、整体氛围
2. **再分别按模版写每个角色**：每个角色按下方模板结构完整填写，各自独立成块

```
<World_NPC_$Name>
角色档案:
  组群简述: ${这组角色的共同点——身份、环境、整体氛围，如"沈府后宅的一群下人仆妇，各司其职，彼此熟识却各有心思"}

  <World_NPC_角色甲>
    ...按下方模板完整填写角色甲...
  </World_NPC_角色甲>

  <World_NPC_角色乙>
    ...按下方模板完整填写角色乙...
  </World_NPC_角色乙>
</World_NPC_$Name>
```

**注意**：
- 只有**同类型、同场景**的角色适合合并（同一群仆人、同一家人、同一社团成员）；互不相关的角色应各自独立条目
- 每个角色仍需完整的初始信息、性格、与主角的相遇可能等字段，不可因合并而省略
- 标签按 `角色名` 区分，如 `<World_NPC_王妈>`、`<World_NPC_春杏>`

## 模板结构

```
<World_NPC_$Name>
角色档案:
  初始信息:
    姓名: ${姓名}
    年龄: ${年龄}
    性别: ${性别}
    身份: ${按场合拆分的不同身份}
    样貌: ${简要样貌介绍}
    体格: ${简要体格介绍}
    社交情况: ${社交圈子，日常接触人群，与谁相识、与谁交好或交恶等}

  出身: ${分条介绍来历、历史事件等}

  现状: ${分条介绍当前处境}

  社交关系:
    与主角的关系: ${与主角的关系定位、认识过程、互动方式等}
    与其他角色的关系: ${与重要角色的关系，写具体画面而非抽象评价}
    在所属圈层的关系: ${在所处社交圈/行业/组织内的位置与关系网络}

  与主角的相遇可能和展开方向: ${可能在什么场景下遇到主角，相遇后可能的发展方向，如可发展关系、可提供帮助、可形成冲突等}

  初始长期目标: ${1-3条，方向各不相同，根据角色信息设定合理的长期目标}
  初始短期目标: ${1-3条，方向各不相同，根据角色现状设定合理的短期目标}

  本领: ${角色拥有的技能和水平}

  性格信息:
    待人接物倾向: ${与他人互动时的思维方式、行为准则、认知状态}
    突发处理倾向: ${处理突发问题时的思维方式、行为准则、认知状态}
    对待善恶倾向: ${面对善事和恶事时的思维方式、行为准则、认知状态}
    对待强弱倾向: ${面对强于自己和弱于自己的人事物时的思维方式、行为准则、认知状态}
    自我推进倾向: ${无目标或完成前一目标后的思维方式、行为准则、认知状态}

  NSFW信息:
    器官信息:
      口: ${唇形、口唇状态、口腔软腭与舌部特点、口部敏感度等}
      胸: ${胸部大小及形态、哺乳器官特征、乳晕颜色与尺寸、敏感度等}
      臀: ${臀型、丰盈程度、触感特点、敏感度等}
      外阴: ${外阴形态及毛发特征、大小阴唇形态、阴蒂位置与大小、敏感度等}
      内阴: ${阴道内壁特征、深浅与紧致度、子宫形态及位置、敏感点位置等}
      肛门谷道: ${肛门形态、谷道深浅与紧致度、敏感度、耐受程度等}
      性能: ${敏感度整体评估、湿润程度、高潮特点、反应方式等}
      性知识了解程度: ${对性知识的了解程度，来源为何，是否有实践经验等}
    档案信息:
      历史: ${过往性经历等信息}
      倾向: ${倾向}
      习惯: ${习惯}
      认知: ${认知}
      爱好: ${爱好}

  注释信息: ${其他需注意的信息}

</World_NPC_$Name>
```

## 字段说明

### 初始信息

| 字段 | 说明 |
|------|------|
| 姓名 | 角色姓名 |
| 年龄 | 年龄 |
| 性别 | 性别 |
| 身份 | **按场合拆分**——同一角色在不同场景下身份不同 |
| 样貌 | 简要样貌介绍，遵循"外貌只写特征"原则 |
| 体格 | 体态特征、力量感、健康状况 |
| 社交情况 | 社交范围、日常接触人群、与谁相识、与谁交好或交恶 |

### 出身

角色来历和关键事件。只写对角色产生了实际影响的事。

### 现状

当前处境。分条说明。

### 社交关系

内部按方向划分，写具体画面而非抽象评价：

| 方向 | 说明 |
|------|------|
| 与主角的关系 | 关系定位、认识过程、互动方式等 |
| 与其他角色的关系 | 与重要角色的关系，具体画面 |
| 在所属圈层的关系 | 在所处社交圈/行业/组织内的位置与关系网络 |

### 与主角的相遇可能和展开方向

**核心字段**。描述：
- 可能在什么场景下遇到主角
- 相遇后可能的发展方向：可发展关系、可提供帮助、可形成冲突、可推进剧情等
- 此角色与主角的互动可能产生什么后果

### 目标

- **长期目标**：角色最终想达成的状态，驱动角色长期行动。写 1-3 条，每条方向各不相同
- **短期目标**：当前最紧迫要做的事，是角色近期的行动指南。写 1-3 条，每条方向各不相同

### 本领

角色拥有的技能和水平。

### 性格信息

五项倾向，同主角模板。每个倾向写具体的行为模式和认知状态，不写抽象标签。

### NSFW 信息

| 字段 | 说明 |
|------|------|
| 口 | 唇形、口唇状态、口腔软腭与舌部特点、口部敏感度等 |
| 胸 | 胸部大小及形态、哺乳器官特征、乳晕颜色与尺寸、敏感度等 |
| 臀 | 臀型、丰盈程度、触感特点、敏感度等 |
| 外阴 | 外阴形态及毛发特征、大小阴唇形态、阴蒂位置与大小、敏感度等 |
| 内阴 | 阴道内壁特征、深浅与紧致度、子宫形态及位置、敏感点位置等 |
| 肛门谷道 | 肛门形态、谷道深浅与紧致度、敏感度、耐受程度等 |
| 性能 | 敏感度整体评估、湿润程度、高潮特点、反应方式等 |
| 性知识了解程度 | 对性知识的了解程度、来源（书本/实践/听闻）、是否有实践经验 |
| 历史 | 过往性经历 |
| 倾向 | 性倾向、偏好 |
| 习惯 | 性方面的习惯行为 |
| 认知 | 对性和两性关系的认知与态度 |
| 爱好 | 在性方面的具体爱好 |

### 注释信息

其他需要注意的信息。

## 编写顺序

- NPC 模板在创作规划中列为 `entries` 中的一条，类型为 `NPC`，part 为 `major`
- 编写时直接产出完整条目，不再拆分
- 编写完成后在 entryManifest 中注册为 `NPC/{角色名}_NPC`，使用 `<World_NPC_$Name>` 标签

## 自查清单

- [ ] 身份按场合拆分，至少两个不同场景
- [ ] 若一个条目写多个角色：有整体简述，且每个角色都按模板完整填写、标签按角色名区分
- [ ] "与主角的相遇可能和展开方向"已填写，包含至少一种相遇场景和一种发展方向
- [ ] 社交情况已填写
- [ ] 社交关系按方向划分填写（与主角/与其他角色/所属圈层）
- [ ] 长期目标和短期目标各 1-3 条且方向各不相同
- [ ] 五项性格倾向完整，每项有具体行为模式而非抽象标签
- [ ] NSFW 器官信息覆盖口/胸/臀/外阴/内阴/肛门谷道，包含性知识了解程度
- [ ] 通用自查：按 `references/rules.md` 通用自查
