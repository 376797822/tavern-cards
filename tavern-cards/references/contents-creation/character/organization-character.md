# 组织级角色模板

用于编写以"组织/势力"为单位的整体条目。此类条目描述一个组织（帮派、门派、商会、机构、教团等）的集体设定，涵盖概述、现状、势力范围、组织结构、成员、内部关系、对外关系等，供 AI 理解这个组织如何运作、谁掌权、成员如何构成。

## 约束

- 组织级条目以**组织/势力整体**为对象，不是单个角色
- 条目使用 `<World_Org_$Name>` XML 标签，`$Name` 替换为组织名（如"临江商会""暗月教"）
- 此模板整合了组织概述、结构、成员、关系网络，不再拆分
- 组织级成员不重复写详细人设——如需主角级/NPC 级的深度设定，单独用对应模版编写，此处只写组织层面的信息
- 不可被 {{user}} 代入

## 模板结构

```
<World_Org_$Name>
组织档案:
  概述: ${组织整体定位——是什么组织、性质（公开/隐秘/合法/非法）、在世间的影响与地位}

  现状: ${分条介绍组织当前处境、主要困境和机会}

  初始长期目标: ${1-3条，方向各不相同，根据组织信息设定合理的长期目标}
  初始短期目标: ${1-3条，方向各不相同，根据组织现状设定合理的短期目标}

  势力范围: ${组织的势力覆盖——地域、产业、渠道、控制或影响的领域}

  经济情况: ${资金来源、收入水平、主要开销、财务状况}

  组织结构:
    首领/核心层: ${最高决策者、核心决策层的构成与分工}
    层级与部门: ${组织内部分层——堂口/分舵/部门等，各自职能}
    加入与晋升: ${成员如何加入、如何晋升}

  成员:
    核心成员: ${按人列出，每人姓名、职位、一句话定位}
    普通成员概况: ${普通成员的数量规模、构成、典型形象}
    依附/外围人员: ${与组织有关联但非正式成员的势力或个人}

  成员住址/据点:
    总部/主要据点: ${组织的大本营位置、布局}
    分舵/分部: ${各分部位置及负责人}
    关键成员居所: ${核心成员常驻/居住地点}

  内部关系:
    权力格局: ${组织内部权力分布——谁掌权、谁有实权、谁在上升/失势}
    主要派系/矛盾: ${内部派系、矛盾、忠诚与背叛线}

  对外关系:
    结盟/合作: ${与哪些势力结盟或合作}
    敌对/竞争: ${与哪些势力敌对或竞争}
    依附/受制: ${依附于谁、受制于谁}

  其他信息: ${组织信条、禁忌、秘密、历史包袱等其他需注意的信息}

</World_Org_$Name>
```

## 字段说明

### 概述

组织整体定位。什么组织、什么性质（公开/隐秘/合法/非法）、在世间的影响与地位。

### 现状

组织当前处境。分条说明，覆盖主要困境和机会。

### 目标

- **长期目标**：组织最终想达成的状态（如扩张势力、称霸一方、完成使命），写 1-3 条，每条方向各不相同
- **短期目标**：组织当前最紧迫要做的事，写 1-3 条，每条方向各不相同

### 势力范围

组织的势力覆盖——地域、产业、渠道、控制或影响的领域。决定组织在城中能调动什么资源、影响哪些层面。

### 经济情况

资金来源、收入水平、主要开销、财务状况。

### 组织结构

- **首领/核心层**：最高决策者、核心决策层的构成与分工
- **层级与部门**：组织内部分层——堂口/分舵/部门等，各自职能
- **加入与晋升**：成员如何加入、如何晋升

### 成员

- **核心成员**：按人列出——姓名、职位、一句话定位
- **普通成员概况**：数量规模、构成、典型形象
- **依附/外围人员**：与组织有关联但非正式成员的势力或个人

### 成员住址/据点

- **总部/主要据点**：组织的大本营位置、布局
- **分舵/分部**：各分部位置及负责人
- **关键成员居所**：核心成员常驻/居住地点

### 内部关系

- **权力格局**：组织内部权力分布——谁掌权、谁有实权、谁在上升/失势
- **主要派系/矛盾**：内部派系、矛盾、忠诚与背叛线

### 对外关系

- **结盟/合作**：与哪些势力结盟或合作
- **敌对/竞争**：与哪些势力敌对或竞争
- **依附/受制**：依附于谁、受制于谁

### 其他信息

组织信条、禁忌、秘密、历史包袱等其他需注意的信息。

## 编写顺序

- 组织级模板在创作规划中列为 `entries` 中的一条，类型按组织在剧情中的定位归入 `角色` 或 `NPC`，part 为 `organization`
- 编写时直接产出完整条目
- 编写完成后在 entryManifest 中注册为 `角色/{组织名}_组织` 或 `NPC/{组织名}_组织`，使用 `<World_Org_$Name>` 标签
