# 功能级角色模板

用于编写功能型角色——这类角色本身很少参与剧情，主要作用是引入新剧情、新人物、完结当前剧情、提供关键信息、指派任务、牵线搭桥等。如上司、媒婆、信使、接头人等。

## 约束

- 功能级角色不可被 {{user}} 代入
- 条目使用 `<World_Function_$Name>` XML 标签，`$Name` 替换为角色名
- 信息量简略，只写够用即可
- 核心字段是"功能定位"，随角色设定变化
- 不写五项性格倾向，只用 1-2 句话概括核心性格
- 不写 NSFW 信息（除非剧情必需）
- 不出现在"与主角相遇可能"字段——功能级角色的出场由剧情需要驱动，不由角色意志决定

## 模板结构

```
<World_Function_$Name>
角色档案:
  初始信息:
    姓名: ${姓名}
    年龄: ${年龄}
    性别: ${性别}
    身份: ${身份}
    样貌: ${简要样貌，一句话}
    社交情况: ${社交范围，与何人相识、在什么圈层活动等}

  功能定位: ${主要功能——引入新剧情、引入新人物、完结当前剧情、提供关键信息、指派任务、牵线搭桥等，随角色设定变化}

  出身: ${极简来历，1-2条}

  现状: ${当前处境，1-2条}

  初始长期目标: ${1-3条，方向各不相同，根据角色信息设定合理的长期目标}
  初始短期目标: ${1-3条，方向各不相同，根据角色现状设定合理的短期目标}

  社交关系:
    与主角的关系: ${与主角的关系定位、认识过程、互动方式等}
    与其他角色的关系: ${与重要角色的关系，具体画面而非抽象评价}
    在所属圈层的关系: ${在所处社交圈/行业/组织内的位置与关系网络}

  性格信息: ${极简性格描述，1-2句话概括核心特质}

  注释信息: ${其他需注意的信息}

</World_Function_$Name>
```

## 字段说明

### 初始信息

| 字段 | 说明 |
|------|------|
| 姓名 | 角色姓名 |
| 年龄 | 年龄，可省略 |
| 性别 | 性别 |
| 身份 | 身份，一句话即可，不需要按场合拆分 |
| 样貌 | 极简要样貌，一句话。不需要"外貌只写特征"的严格审查 |
| 社交情况 | 社交范围，与何人相识、在什么圈层活动。决定此角色在城中能协调什么资源 |

### 功能定位

**核心字段**。描述此角色在剧情中的功能作用。随角色设定变化：

| 功能类型 | 角色示例 | 功能定位描述 |
|---------|---------|-------------|
| 指派任务 | 上司、掌柜、工头 | 每天在铺子里分派活计，给主角提供经济来源和任务线索 |
| 牵线搭桥 | 媒婆、牙人、中间人 | 在各方之间传递消息，撮合生意或亲事 |
| 引入新剧情 | 信使、报信人 | 带来一封密信，将主角卷入新的事件 |
| 引入新人物 | 引荐人、介绍人 | 把新角色带到主角面前 |
| 完结当前剧情 | 公差、官差 | 宣布结案、抓人、或带来一个了结 |
| 提供关键信息 | 老吏、掌柜、街头闲汉 | 知道一些主角不知道的事，在特定条件下说出来 |

### 出身

极简来历，1-2 条即可，够用为度。

### 现状

当前处境，1-2 条。

### 目标

- **长期目标**：写 1-3 条，每条方向各不相同
- **短期目标**：写 1-3 条，每条方向各不相同

### 社交关系

功能级角色社交关系保持极简，内部按方向划分：

| 方向 | 说明 |
|------|------|
| 与主角的关系 | 关系定位、认识过程、互动方式等，1-2 条 |
| 与其他角色的关系 | 与重要角色的关系，写具体画面而非抽象评价 |
| 在所属圈层的关系 | 在所处社交圈/行业/组织内的位置与关系网络 |

### 性格信息

1-2 句话概括核心特质。不需要写五项倾向。

### 注释信息

其他需要注意的信息，如与谁有特殊关系、在什么条件下会触发功能等。

## 编写顺序

- 功能级模板在创作规划中列为 `entries` 中的一条，类型为 `NPC`，part 为 `function`
- 编写时直接产出完整条目
- 编写完成后在 entryManifest 中注册为 `NPC/{角色名}_功能`，使用 `<World_Function_$Name>` 标签

## 自查清单

- [ ] 功能定位明确，写明此角色在剧情中的作用
- [ ] 长期目标和短期目标各 1-3 条且方向各不相同
- [ ] 社交关系按方向划分填写（与主角/与其他角色/所属圈层）
- [ ] 没有出现"与主角相遇可能"字段——功能级角色不由自身意志决定出场
- [ ] 没有不必要的信息量——够用为度
- [ ] 通用自查：按 `references/rules.md` 通用自查
